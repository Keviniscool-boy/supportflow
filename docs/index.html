可审计的 Agent 路由

显式状态机为每个 Agent 定义路由边界与执行许可，便于 Governance 与审计。

类型化工具（Typed Tools）

业务操作（订单查询、工单创建等）通过类型化接口受控调用，降低误操作风险。

知识库引用与溯源

基于企业知识库的回答带可追溯引用，支持证据来源的审计与回溯。

快速开始

在本地以 Mock 模式运行后端（Go 环境）
git clone https://github.com/Keviniscool-boy/supportflow.git
cd supportflow
export SUPPORTFLOW_ENV=development
export SUPPORTFLOW_MODEL_MODE=mock
go run ./cmd/server
# 打开 http://localhost:8080 查看 demo 接口

适合谁使用

客服平台工程师、知识运营负责人、SRE/DevOps、想搭建自托管智能客服的公司或团队。
